I am building an open-source, privacy-first local AI desktop assistant in Python designed for Windows users who want to automate daily system tasks without relying on cloud-based telemetry. The project integrates local LLMs via Ollama (such as Qwen) with the Telegram Bot API, enabling users to remotely trigger desktop applications, inspect screen context, schedule reminders, and manage communications using a PIN-authenticated workflow. It fills a practical gap in the ecosystem by offering a lightweight, self-hosted alternative to heavy commercial agents for developers and power users on standard workstation hardware.
